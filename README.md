# xuxiang-wang.github.io

Personal website of Xuxiang Wang, served by GitHub Pages at https://xuxiang-wang.github.io.

- `index.html`: homepage
- `projects/gold-bitcoin/`: interactive backtest, built from https://github.com/xuxiang-wang/gold-bitcoin-trading
- `projects/raw-materials/`: interactive plan, built from https://github.com/xuxiang-wang/raw-material-ordering

Each page is a single self-contained HTML file. To update a project page, run `node website/build.js` in its code repository and copy `website/index.html` here.
